BASE DOTACION - COBERTURA

Subí la base de dotación y descargá el Excel limpio: se quitan las dos primeras filas, se dejan solo las áreas de cobertura y se descartan terciaria, BEDEL e IFTS.

Limpiar base

Procedimiento:
  • Se eliminan las primeras 2 filas del archivo.
  • Columna AREA: solo quedan las áreas de cobertura listadas.
  • Columna CARGO: se eliminan los que mencionan terciaria o BEDEL.
  • Se eliminan vacantes de establecimientos IFTS.

Cómo funciona BASE DOTACION - COBERTURA

  • Primeras 2 filas: se descartan (títulos / filas de más del archivo) y después se detecta el encabezado.
  • Áreas que quedan: Educación Media, Curricular de Materias Especiales, Primaria, Artística, Adulto y Adolescente, Técnica, Especial, Programas Socioeducativos, Superior, Inicial y Servicios Profesionales.
  • CARGO: si el texto contiene terciaria (o terciario) o BEDEL, la fila sale.
  • IFTS: si el establecimiento (o la fila) menciona IFTS / I.F.T.S., la fila sale.
  • Excel de salida: hoja 1 Base limpia y hoja 2 Descartados (con columna MOTIVO).
