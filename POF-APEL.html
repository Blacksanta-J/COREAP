Cómo funciona POF APEL

  • Archivo (BASE HARBOUR): se detecta la fila de encabezados y se leen todas las hojas con datos.
  • Salida: un Excel con las columnas DNI, COD AREA, ID CARGO, ID ASIGNATURA, ID ESPECIALIDAD, FECHA COMIENZO, TURNO, HORAS, ID ESTABLECIMIENTO e ID POF (en ese orden).
  • COD AREA: se calcula desde el texto de AREA ESTABLECIMIENTO (tabla de códigos). Adultos: CENS/ANEXO CENS en el nombre de escuela → 10; si no → 4.
  • Transformación: DOCUMENTO DESIGNADO → DNI, ID PLAN → ID ESPECIALIDAD, TURNO 1 → TURNO, etc.
  • HORAS: sale como número entero (sin decimales). Si viene vacío o en 0, se carga 1.
  • ID ASIGNATURA / ID ESPECIALIDAD: si el valor es solo 0, queda vacío.
  • Id. POF duplicados: se quita la repetición (se conserva la primera aparición).
