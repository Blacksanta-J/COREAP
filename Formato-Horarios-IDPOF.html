Formato Horarios x IDPOF

Subí un archivo con Id. POF repetidos (un horario por fila). Se agrupa todo el horario de cada Id. POF en una sola celda.

Agrupar horarios

Se usa la columna Id. POF (o equivalentes) para agrupar. Por defecto: columna L = día · M = desde · N = hasta. Si L/M/N no tienen datos, se buscan encabezados DIA, DESDE / HASTA. Días: LU MA MI JU VI SA DO. Salida:
LU-18:15-23:15|MA-18:15-23:15|MI-18:15-23:15|JU-18:15-23:15|VI-18:15-23:15

Cómo funciona Formato Horarios x IDPOF

  • Archivo: una fila por tramo horario. El mismo Id. POF puede repetirse.
  • Id. POF: se detecta por encabezado (Id. POF, IDPOF, ID POF, Número de propuesta, etc.).
  • Día / desde / hasta: columnas L, M y N. Si vienen vacías, se usan columnas llamadas día, desde y hasta.
  • Días aceptados: lunes→LU, martes→MA, miércoles→MI, jueves→JU, viernes→VI, sábado→SA, domingo→DO (también LU, MA, etc.).
  • Horas: se normalizan a HH:MM (acepta 18:15, 18.15, hora de Excel).
  • Agrupado: se unen los tramos del mismo Id. POF, se sacan duplicados y se ordenan LU→DO.
  • Excel de salida: hoja 1 Horarios (Id. POF + HORARIO) y hoja 2 Agrupado (primera fila de cada Id. POF con la columna HORARIO completa).
