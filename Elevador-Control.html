Modificador de Archivos

Seleccioná el Archivo Base (XLSX o CSV) para unificar sus hojas y aplicar el formato requerido.

Procesos Aplicados

Al procesar el archivo, se aplican automáticamente las siguientes reglas:

  • Unificación: Se combinan todas las hojas del Excel base en una sola.
  • Estructura: Se genera una columna inicial vacía y se ordena todo según el formato del Archivo Resultado.
  • Mapeo de Áreas: Se normalizan los nombres y se asigna su "Código de Área" (Ej: Tecnica = 16).
  • Mapeo de Turnos: Conversión de letras (M, T, N, etc.) a palabras completas (Mañana, Tarde, NOCHE, Completo).
  • Campos Vacíos / Fijos:
    • Sit. Rev. queda como "INTERINO".
    • Base/Ascenso y Tipo de Listado toman valor "3".
    • Novedad mayor a 60 días se setea en "2".
    • Si Distrito o Número de Escuela vienen vacíos, se autocompletan con "1".
    • Si los códigos de Asignatura o Especialidad son "0", se vacían.
    • Motivo y Docente vacíos se rellenan con un ".".
  • Horas: Se eliminan los decimales de la "Cant. Horas" (Si viene en 0 o vacía, se pone 1).
  • Formato Nativo: Las fechas de apertura, publicación, desde y hasta (31/12/del año actual) adquieren formato serial compatible con Excel.
  • Nombrado: El archivo descargado incluirá el Área, la palabra "CONTROL" y la fecha de exportación.
  • Informe: Se genera una segunda hoja con el conteo de vacantes por área y por cargo.
