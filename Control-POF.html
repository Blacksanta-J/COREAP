Control POF

Cruzá el archivo POF (solo TITULAR) con el segundo listado de docentes y descargá un Excel con coincidencias y no coincidencias, en formato POF.

Cruce de archivos

Columnas equivalentes para el cruce: ID CARGO = COD CARGO · ID ASIGNATURA = COD ASIGNATURA · DOCUMENTO DESIGNADO = NDOC. No se cruza ID PLAN / COD ESPECIALIDAD. Del POF se conservan únicamente las filas con CARACTER = TITULAR. En esas columnas de cruce, si el valor es solo 0 se vacía (queda en blanco). Antes de comparar, los cargos 1550, 1504, 1549, 1507 y 1528 se tratan como 1599. En el Excel final se eliminan Id. POF duplicados.

Cómo funciona Control POF

  • Archivo 1 (POF): se leen las hojas, se detecta la fila de encabezados y se descartan las filas cuyo CARACTER no sea TITULAR.
  • Archivo 2: listado de docentes a cruzar. Se usan NDOC, COD CARGO y COD ASIGNATURA (o sus equivalentes del POF).
  • Ceros en el POF: en las columnas de cruce (ID CARGO, ID ASIGNATURA, DOCUMENTO DESIGNADO), si el valor es solo 0 se vacía antes de comparar y en el Excel de salida.
  • Equivalencia de cargo: los códigos 1550, 1504, 1549, 1507 y 1528 se convierten a 1599 antes de comparar (en POF y en el archivo 2) y quedan como 1599 en el Excel de salida del POF.
  • Clave de coincidencia: documento + código de cargo + código de asignatura. No se usa ID PLAN / COD ESPECIALIDAD.
  • Id. POF duplicados: en el resultado final se elimina la repetición de Id. POF (se conserva la primera aparición; los vacíos no se agrupan).
  • Excel de salida (formato POF): hoja 1 Coincidieron (TITULAR del POF presentes en el segundo archivo) y hoja 2 No coincidieron (TITULAR del POF que no están en el segundo archivo).
